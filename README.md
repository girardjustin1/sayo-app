# SAYO

A private, stigma-free health app for young women: ask in your own words, get evidence-based information,
optional review by a verified health professional, find the right care, and a protected peer Circle.

**Phase 1 is design in Storybook.** Every screen and state is a story. All data is fictional.

```bash
pnpm install
pnpm storybook      # http://localhost:6030
pnpm check          # typecheck + tests
```

Start with **Start Here** in Storybook, then **Brand → Directions**. Product source of truth:
[`docs/SAYO_MASTER_CONTEXT.md`](docs/SAYO_MASTER_CONTEXT.md). Built on [Astryx](https://astryx.atmeta.com).
